Osadź kalkulator na swojej stronie

Dwa sposoby na umieszczenie kalkulatora Telegram Stars na stronie. Oba są darmowe.

Opcja 1: iframe

Wklej to tam, gdzie ma się pojawić kalkulator. Pokazuje aktualne ceny i mieści się w kolumnach od 320 px szerokości.

<iframe src="https://giftclub.app/embed/telegram-stars-calculator" title="Kalkulator Telegram Stars" width="100%" height="880" style="max-width:480px;border:0;display:block" loading="lazy"></iframe>

Linia z podziękowaniem pod spodem jest mile widziana, ale niewymagana:

<p style="max-width:480px;font-size:14px">Kalkulator Telegram Stars · <a href="https://giftclub.app/pl/blog/buy-telegram-stars">Gift Club</a></p>

Podgląd

Opcja 2: komponent web

Hostowany u Ciebie i w pełni stylowalny: skrypt działa na Twojej stronie, nie renderuje linków i nie wysyła zapytań.

<script type="module" src="https://cdn.jsdelivr.net/npm/@gift-club/telegram-stars-calculator@1.0.0/src/widget.js"></script>
<telegram-stars-calculator lang="pl"></telegram-stars-calculator>

Dopasuj do swojego motywu za pomocą zmiennych CSS:

telegram-stars-calculator {
  --tsc-bg: #0d0b14;
  --tsc-ink: #f3f0fa;
  --tsc-muted: #a59fb5;
  --tsc-line: #2a2535;
  --tsc-accent: #ffcf4a;
}

Pytania

Czy osadzanie jest darmowe?

Tak, na każdej stronie, także komercyjnej.

Czy osadzony kalkulator śledzi odwiedzających?

Komponent web nie ustawia ciasteczek i nie wysyła żadnych zapytań sieciowych. Iframe to strona giftclub.app, która liczy odwiedziny przez Google Analytics; jeśli nie chcesz żadnych zapytań do stron trzecich, użyj komponentu web.

Jakie języki obsługuje?

Komponent web mówi po angielsku, rosyjsku, ukraińsku, hiszpańsku, polsku, włosku, turecku, niemiecku i francusku.
