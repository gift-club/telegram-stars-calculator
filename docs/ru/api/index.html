Справочник по API

Все функции чистые и синхронные. Количество звёзд ограничено диапазоном от 1 до 100 000; страна задаётся кодом ISO, например "us" или "de".

compare(stars, store = "us")

Оба способа купить stars в одной стране. saving показывает, насколько звезда дешевле на Fragment, в виде доли, или null, если в снимке нет курса для этой валюты.

compare(1000, "ru");
// { stars: 1000,
//   appStore: { store: "ru", currency: "RUB", price: 2120, stars: 1000, packs: [{stars:500,count:2}] },
//   fragment: { stars: 1000, usd: 15, currency: "RUB", local: 1259.25 },
//   saving: 0.4060 }

appStorePlan(stars, store = "us")

Наборы App Store для покупки: наименьшая сумма не меньше stars, которую можно собрать из наборов страны, за минимум покупок. Для неизвестной страны бросает RangeError.

appStorePlan(1200, "us").packs;
// [{"stars":1000,"count":1},{"stars":100,"count":2}]

fragmentPlan(stars, currency = "USD")

Цена Fragment за stars (не меньше его минимума) в долларах и, если в снимке есть курс, в currency.

fragmentPlan(10);         // { stars: 50, usd: 0.75, currency: "USD", local: 0.75 }

starsToUsd(stars) / usdToStars(usd)

Звёзды в доллары и обратно по фиксированной ставке Fragment.

starsToUsd(1000); // 15
usdToStars(15);   // 1000

STORES, APP_STORES, FRAGMENT_USD_PER_STAR, USD_RATES

Сам снимок: наборы каждой страны с датой чтения, ставка и минимум Fragment, курсы валют.

TypeScript

Типы лежат в src/index.d.ts и подключаются автоматически.
