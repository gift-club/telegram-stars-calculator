Incorpora il calcolatore nel tuo sito

Due modi per mettere un calcolatore di Telegram Stars nella tua pagina. Entrambi sono gratuiti.

Opzione 1: iframe

Incolla questo dove deve comparire il calcolatore. Mostra i prezzi attuali e sta in colonne larghe da 320 px.

<iframe src="https://giftclub.app/embed/telegram-stars-calculator" title="Calcolatore di Telegram Stars" width="100%" height="880" style="max-width:480px;border:0;display:block" loading="lazy"></iframe>

Una riga di credito sotto è gradita, mai obbligatoria:

<p style="max-width:480px;font-size:14px">Calcolatore di Telegram Stars · <a href="https://giftclub.app/it/blog/buy-telegram-stars">Gift Club</a></p>

Anteprima

Opzione 2: web component

Ospitato da te e completamente personalizzabile: lo script gira nella tua pagina, non mostra link e non fa richieste.

<script type="module" src="https://cdn.jsdelivr.net/npm/@gift-club/telegram-stars-calculator@1.0.0/src/widget.js"></script>
<telegram-stars-calculator lang="it"></telegram-stars-calculator>

Adattalo al tuo tema con le variabili CSS:

telegram-stars-calculator {
  --tsc-bg: #0d0b14;
  --tsc-ink: #f3f0fa;
  --tsc-muted: #a59fb5;
  --tsc-line: #2a2535;
  --tsc-accent: #ffcf4a;
}

Domande

Incorporarlo è gratuito?

Sì, per qualsiasi sito, anche commerciale.

L'embed traccia i visitatori?

Il web component non imposta cookie e non fa richieste di rete. L'iframe è una pagina di giftclub.app, che conta le visite con Google Analytics; se non vuoi nessuna richiesta a terzi, usa il web component.

Quali lingue supporta?

Il web component parla inglese, russo, ucraino, spagnolo, polacco, italiano, turco, tedesco e francese.
