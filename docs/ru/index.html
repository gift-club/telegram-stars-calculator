Калькулятор Telegram Stars для JavaScript

Узнай, сколько стоит любое число Telegram Stars на Fragment и в App Store в 18 странах, в Node.js или в браузере. Без зависимостей и сетевых запросов.

Цены обновлены: 2026-10-30

1 000 Telegram Stars стоят 15,00 $ на Fragment и 19,99 $ в американском App Store, так что на Fragment одна звезда дешевле на 25 %. Пакет возвращает эти цифры для любого количества и любой страны.

Установка

npm install @gift-club/telegram-stars-calculator
import { compare } from "@gift-club/telegram-stars-calculator";

const r = compare(1000, "us");
r.fragment.usd;     // 15
r.appStore.price;   // 19.99
r.saving;           // 0.2496

compare() возвращает обе цены, наборы для покупки в App Store и экономию. Fragment продаёт любое количество от 50 звёзд по 0,015 $ за штуку; App Store продаёт фиксированные наборы, поэтому план округляет вверх до ближайшего количества, которое можно собрать из наборов.

Готовый виджет

Один тег script добавляет элемент <telegram-stars-calculator> на девяти языках. Он целиком работает на странице, не рисует ссылок и не отправляет запросов.

<script type="module" src="https://cdn.jsdelivr.net/npm/@gift-club/telegram-stars-calculator@1.0.0/src/widget.js"></script>
<telegram-stars-calculator lang="ru" store="ru" stars="1000"></telegram-stars-calculator>

Что умеет

  • Считает любое количество от 1 до 100 000 звёзд в 18 странах App Store, в валюте каждого магазина.
  • Подбирает наборы App Store: наименьшее количество не меньше запрошенного, за минимум покупок.
  • Переводит доллары Fragment в валюту каждого магазина по курсу центрального банка на дату.
  • Поставляется с типами TypeScript, ES-модулями и тестами; работает в Node 18+ и во всех современных браузерах.

Вопросы

Сколько стоят 1 000 Telegram Stars в долларах?

15,00 $ на Fragment и 19,99 $ в американском App Store.

Пакет загружает актуальные цены?

Нет. Внутри снимок цен с датой, поэтому результаты повторяемы и работают офлайн. Чтобы получить новые цены, обнови пакет.

Можно использовать в коммерческом приложении или боте?

Да, лицензия MIT.

Почему нет цены Google Play?

У Google Play нет публичного прайс-листа, который можно было бы прочитать, поэтому пакет охватывает только Fragment и App Store.
