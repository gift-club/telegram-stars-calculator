Telegram-Stars-Rechner für JavaScript

Berechne, was beliebig viele Telegram Stars bei Fragment und im App Store von 18 Ländern kosten, in Node.js oder im Browser. Keine Abhängigkeiten, keine Netzwerkaufrufe.

Preise gelesen am: 2026-10-30

1.000 Telegram Stars kosten bei Fragment 15,00 $ und im US-App-Store 19,99 $, also ist ein Stern bei Fragment 25 % günstiger. Das Paket liefert diese Zahlen für jede Menge und jedes Land.

Installation

npm install @gift-club/telegram-stars-calculator
import { compare } from "@gift-club/telegram-stars-calculator";

const r = compare(1000, "us");
r.fragment.usd;     // 15
r.appStore.price;   // 19.99
r.saving;           // 0.2496

compare() liefert beide Preise, die im App Store zu kaufenden Pakete und die Ersparnis. Fragment verkauft jede Menge ab 50 Sternen für je 0,015 $; der App Store verkauft feste Pakete, deshalb rundet der Plan auf die kleinste Menge auf, die sich aus den Paketen bilden lässt.

Fertiges Widget

Ein einziges Script-Tag fügt ein <telegram-stars-calculator>-Element in neun Sprachen ein. Es läuft komplett auf der Seite, zeigt keine Links und sendet keine Anfragen.

<script type="module" src="https://cdn.jsdelivr.net/npm/@gift-club/telegram-stars-calculator@1.0.0/src/widget.js"></script>
<telegram-stars-calculator lang="de" store="de" stars="1000"></telegram-stars-calculator>

Widget ausprobieren

Was es kann

  • Berechnet jede Menge von 1 bis 100.000 Sternen in 18 App-Store-Ländern, in der Währung des jeweiligen Stores.
  • Findet die zu kaufenden App-Store-Pakete: die kleinste Menge, die mindestens der gewünschten entspricht, mit möglichst wenigen Käufen.
  • Rechnet den Dollarpreis von Fragment mit einem datierten Zentralbankkurs in die Währung jedes Stores um.
  • Bringt TypeScript-Typen, ES-Module und Tests mit; läuft in Node 18+ und in allen modernen Browsern.

Fragen

Wie viele Dollar kosten 1.000 Telegram Stars?

15,00 $ bei Fragment und 19,99 $ im US-App-Store.

Ruft das Paket Live-Preise ab?

Nein. Es enthält einen datierten Schnappschuss, deshalb sind die Ergebnisse reproduzierbar und funktionieren offline. Aktualisiere das Paket, um neuere Preise zu bekommen.

Kann ich es in einer kommerziellen App oder einem Bot nutzen?

Ja, es steht unter der MIT-Lizenz.

Warum gibt es keinen Google-Play-Preis?

Google Play veröffentlicht keine öffentliche Preisliste, die sich auslesen ließe, deshalb deckt das Paket nur Fragment und den App Store ab.
