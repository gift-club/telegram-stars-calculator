Referencia de la API

Todas las funciones son puras y síncronas. Las cantidades se limitan a un rango de 1 a 100 000 Estrellas; un país es un código ISO como "us" o "de".

compare(stars, store = "us")

Las dos formas de comprar stars en un país. saving indica cuánto menos cuesta una Estrella en Fragment, como fracción, o null cuando la instantánea no tiene tipo de cambio para esa moneda.

compare(1000, "ru");
// { stars: 1000,
//   appStore: { store: "ru", currency: "RUB", price: 2120, stars: 1000, packs: [{stars:500,count:2}] },
//   fragment: { stars: 1000, usd: 15, currency: "RUB", local: 1259.25 },
//   saving: 0.4060 }

appStorePlan(stars, store = "us")

Los paquetes de la App Store que hay que comprar: el total más pequeño igual o superior a stars que puedan formar los paquetes del país, con el menor número de compras. Lanza un RangeError si el país es desconocido.

appStorePlan(1200, "us").packs;
// [{"stars":1000,"count":1},{"stars":100,"count":2}]

fragmentPlan(stars, currency = "USD")

El precio de Fragment para stars (como mínimo su cantidad mínima), en dólares y, si la instantánea tiene tipo de cambio, en currency.

fragmentPlan(10);         // { stars: 50, usd: 0.75, currency: "USD", local: 0.75 }

starsToUsd(stars) / usdToStars(usd)

De Estrellas a dólares y viceversa con la tarifa fija de Fragment.

starsToUsd(1000); // 15
usdToStars(15);   // 1000

STORES, APP_STORES, FRAGMENT_USD_PER_STAR, USD_RATES

La instantánea en sí: los paquetes de cada país con la fecha de lectura, la tarifa y el mínimo de Fragment, y los tipos de cambio.

TypeScript

Los tipos se incluyen en src/index.d.ts y se cargan automáticamente.
