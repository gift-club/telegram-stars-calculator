API başvurusu

Tüm fonksiyonlar saf ve eşzamanlıdır. Miktarlar 1–100.000 Yıldız aralığına sınırlanır; ülke, "us" veya "de" gibi bir ISO kodudur.

compare(stars, store = "us")

Bir ülkede stars satın almanın her iki yolu. saving, bir Yıldızın Fragment'te ne kadar ucuz olduğunu kesir olarak verir; anlık görüntüde o para birimi için kur yoksa null olur.

compare(1000, "ru");
// { stars: 1000,
//   appStore: { store: "ru", currency: "RUB", price: 2120, stars: 1000, packs: [{stars:500,count:2}] },
//   fragment: { stars: 1000, usd: 15, currency: "RUB", local: 1259.25 },
//   saving: 0.4060 }

appStorePlan(stars, store = "us")

Satın alınacak App Store paketleri: ülkenin paketleriyle oluşturulabilen, stars değerine eşit veya ondan büyük en küçük toplam, en az satın alma ile. Bilinmeyen bir ülke için RangeError fırlatır.

appStorePlan(1200, "us").packs;
// [{"stars":1000,"count":1},{"stars":100,"count":2}]

fragmentPlan(stars, currency = "USD")

Fragment'in stars için fiyatı (en az kendi minimumu kadar), dolar olarak ve anlık görüntüde kur varsa currency cinsinden.

fragmentPlan(10);         // { stars: 50, usd: 0.75, currency: "USD", local: 0.75 }

starsToUsd(stars) / usdToStars(usd)

Fragment'in sabit oranıyla Yıldızdan dolara ve geri dönüşüm.

starsToUsd(1000); // 15
usdToStars(15);   // 1000

STORES, APP_STORES, FRAGMENT_USD_PER_STAR, USD_RATES

Anlık görüntünün kendisi: her ülkenin paketleri ve okunma tarihi, Fragment'in oranı ve minimumu, döviz kurları.
