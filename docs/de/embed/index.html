Den Rechner auf deiner Website einbetten

Zwei Wege, einen Telegram-Stars-Rechner auf deine Seite zu bringen. Beide sind kostenlos.

Option 1: iframe

Füge das dort ein, wo der Rechner erscheinen soll. Er zeigt die aktuellen Preise und passt in Spalten ab 320 px Breite.

<iframe src="https://giftclub.app/embed/telegram-stars-calculator" title="Telegram-Stars-Rechner" width="100%" height="880" style="max-width:480px;border:0;display:block" loading="lazy"></iframe>

Eine Quellenzeile darunter ist willkommen, aber nie nötig:

<p style="max-width:480px;font-size:14px">Telegram-Stars-Rechner · <a href="https://giftclub.app/de/blog/buy-telegram-stars">Gift Club</a></p>

Vorschau

Option 2: Web Component

Selbst gehostet und voll gestaltbar: Das Script läuft auf deiner Seite, zeigt keine Links und sendet keine Anfragen.

<script type="module" src="https://cdn.jsdelivr.net/npm/@gift-club/telegram-stars-calculator@1.0.0/src/widget.js"></script>
<telegram-stars-calculator lang="de"></telegram-stars-calculator>

Passe es mit CSS-Variablen an dein Theme an:

telegram-stars-calculator {
  --tsc-bg: #0d0b14;
  --tsc-ink: #f3f0fa;
  --tsc-muted: #a59fb5;
  --tsc-line: #2a2535;
  --tsc-accent: #ffcf4a;
}

Fragen

Ist das Einbetten kostenlos?

Ja, für jede Website, auch kommerzielle.

Trackt die Einbettung Besucher?

Die Web Component setzt keine Cookies und stellt keine Netzwerkanfragen. Der iframe ist eine Seite auf giftclub.app, die Besuche mit Google Analytics zählt; wenn du gar keine Anfragen an Dritte willst, nimm die Web Component.

Welche Sprachen unterstützt sie?

Das Web Component spricht Englisch, Russisch, Ukrainisch, Spanisch, Polnisch, Italienisch, Türkisch, Deutsch und Französisch.
