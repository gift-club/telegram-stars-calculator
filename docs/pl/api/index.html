Dokumentacja API

Wszystkie funkcje są czyste i synchroniczne. Ilość jest ograniczona do zakresu 1–100 000 Gwiazdek; kraj to kod ISO, taki jak "us" lub "de".

compare(stars, store = "us")

Oba sposoby kupienia stars w jednym kraju. saving mówi, o ile mniej kosztuje Gwiazdka we Fragment, jako ułamek, albo null, gdy migawka nie ma kursu dla tej waluty.

compare(1000, "ru");
// { stars: 1000,
//   appStore: { store: "ru", currency: "RUB", price: 2120, stars: 1000, packs: [{stars:500,count:2}] },
//   fragment: { stars: 1000, usd: 15, currency: "RUB", local: 1259.25 },
//   saving: 0.4060 }

appStorePlan(stars, store = "us")

Pakiety App Store do kupienia: najmniejsza suma nie mniejsza niż stars, jaką da się złożyć z pakietów danego kraju, w jak najmniejszej liczbie zakupów. Dla nieznanego kraju zgłasza RangeError.

appStorePlan(1200, "us").packs;
// [{"stars":1000,"count":1},{"stars":100,"count":2}]

fragmentPlan(stars, currency = "USD")

Cena Fragment za stars (co najmniej jego minimum) w dolarach i, gdy migawka ma kurs, w currency.

fragmentPlan(10);         // { stars: 50, usd: 0.75, currency: "USD", local: 0.75 }

starsToUsd(stars) / usdToStars(usd)

Gwiazdki na dolary i z powrotem według stałej stawki Fragment.

starsToUsd(1000); // 15
usdToStars(15);   // 1000

STORES, APP_STORES, FRAGMENT_USD_PER_STAR, USD_RATES

Sama migawka: pakiety każdego kraju z datą odczytu, stawka i minimum Fragment oraz kursy walut.

TypeScript

Typy są w src/index.d.ts i ładują się automatycznie.
