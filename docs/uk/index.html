Калькулятор Telegram Stars для JavaScript

Дізнайся, скільки коштує будь-яка кількість Telegram Stars на Fragment і в App Store у 18 країнах, у Node.js або в браузері. Без залежностей і мережевих запитів.

Ціни оновлено: 2026-10-30

1 000 Telegram Stars коштують 15,00 USD на Fragment і 19,99 USD в американському App Store, тож на Fragment одна зірка дешевша на 25%. Пакет повертає ці цифри для будь-якої кількості та країни.

Встановлення

npm install @gift-club/telegram-stars-calculator
import { compare } from "@gift-club/telegram-stars-calculator";

const r = compare(1000, "us");
r.fragment.usd;     // 15
r.appStore.price;   // 19.99
r.saving;           // 0.2496

compare() повертає обидві ціни, набори для купівлі в App Store та економію. Fragment продає будь-яку кількість від 50 зірок по 0,015 USD за штуку; App Store продає фіксовані набори, тому план округлює вгору до найближчої кількості, яку можна скласти з наборів.

Готовий віджет

Один тег script додає елемент <telegram-stars-calculator> дев’ятьма мовами. Він повністю працює на сторінці, не малює посилань і не надсилає запитів.

<script type="module" src="https://cdn.jsdelivr.net/npm/@gift-club/telegram-stars-calculator@1.0.0/src/widget.js"></script>
<telegram-stars-calculator lang="uk" store="us" stars="1000"></telegram-stars-calculator>

Спробувати віджет

Що вміє

  • Рахує будь-яку кількість від 1 до 100 000 зірок у 18 країнах App Store, у валюті кожного магазину.
  • Добирає набори App Store: найменша кількість, не менша за запитану, за мінімум покупок.
  • Переводить долари Fragment у валюту кожного магазину за курсом центрального банку на дату.
  • Постачається з типами TypeScript, ES-модулями й тестами; працює в Node 18+ і в усіх сучасних браузерах.
