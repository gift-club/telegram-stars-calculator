Référence de l’API

Toutes les fonctions sont pures et synchrones. Les quantités sont bornées à 1–100 000 Étoiles ; un pays est un code ISO comme "us" ou "de".

compare(stars, store = "us")

Les deux façons d’acheter stars dans un pays. saving indique combien une Étoile coûte de moins sur Fragment, sous forme de fraction, ou null quand l’instantané n’a pas de taux de change pour cette devise.

compare(1000, "ru");
// { stars: 1000,
//   appStore: { store: "ru", currency: "RUB", price: 2120, stars: 1000, packs: [{stars:500,count:2}] },
//   fragment: { stars: 1000, usd: 15, currency: "RUB", local: 1259.25 },
//   saving: 0.4060 }

appStorePlan(stars, store = "us")

Les packs App Store à acheter : le plus petit total égal ou supérieur à stars que les packs du pays permettent d’obtenir, en un minimum d’achats. Lève une RangeError pour un pays inconnu.

appStorePlan(1200, "us").packs;
// [{"stars":1000,"count":1},{"stars":100,"count":2}]

fragmentPlan(stars, currency = "USD")

Le prix de Fragment pour stars (au moins son minimum), en dollars et, quand l’instantané a un taux, en currency.

fragmentPlan(10);         // { stars: 50, usd: 0.75, currency: "USD", local: 0.75 }

starsToUsd(stars) / usdToStars(usd)

Des Étoiles aux dollars et inversement, au taux fixe de Fragment.

starsToUsd(1000); // 15
usdToStars(15);   // 1000

STORES, APP_STORES, FRAGMENT_USD_PER_STAR, USD_RATES

L’instantané lui-même : les packs de chaque pays avec leur date de relevé, le taux et le minimum de Fragment, et les taux de change.

TypeScript

Les types sont fournis dans src/index.d.ts et se chargent automatiquement.
