API-Referenz

Alle Funktionen sind rein und synchron. Mengen werden auf 1–100.000 Sterne begrenzt; ein Land ist ein ISO-Code wie "us" oder "de".

compare(stars, store = "us")

Beide Wege, stars in einem Land zu kaufen. saving gibt als Bruch an, wie viel weniger ein Stern bei Fragment kostet, oder null, wenn der Schnappschuss keinen Wechselkurs für diese Währung hat.

compare(1000, "ru");
// { stars: 1000,
//   appStore: { store: "ru", currency: "RUB", price: 2120, stars: 1000, packs: [{stars:500,count:2}] },
//   fragment: { stars: 1000, usd: 15, currency: "RUB", local: 1259.25 },
//   saving: 0.4060 }

appStorePlan(stars, store = "us")

Die zu kaufenden App-Store-Pakete: die kleinste Summe, die mindestens stars entspricht und sich aus den Paketen des Landes bilden lässt, mit möglichst wenigen Käufen. Wirft einen RangeError für ein unbekanntes Land.

appStorePlan(1200, "us").packs;
// [{"stars":1000,"count":1},{"stars":100,"count":2}]

fragmentPlan(stars, currency = "USD")

Der Preis von Fragment für stars (mindestens dessen Minimum) in Dollar und, wenn der Schnappschuss einen Kurs hat, in currency.

fragmentPlan(10);         // { stars: 50, usd: 0.75, currency: "USD", local: 0.75 }

starsToUsd(stars) / usdToStars(usd)

Sterne in Dollar und zurück zum festen Fragment-Kurs.

starsToUsd(1000); // 15
usdToStars(15);   // 1000

STORES, APP_STORES, FRAGMENT_USD_PER_STAR, USD_RATES

Der Schnappschuss selbst: die Pakete jedes Landes mit dem Lesedatum, Fragments Kurs und Minimum sowie die Wechselkurse.

TypeScript

Die Typen liegen in src/index.d.ts und werden automatisch geladen.
