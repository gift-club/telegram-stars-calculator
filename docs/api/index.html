API reference

All functions are pure and synchronous. Amounts are clamped to 1–100,000 Stars; a country is an ISO code such as "us" or "de".

compare(stars, store = "us")

Both ways of buying stars in one country. saving is how much less a Star costs on Fragment, as a fraction, or null when the snapshot has no exchange rate for that currency.

compare(1000, "ru");
// { stars: 1000,
//   appStore: { store: "ru", currency: "RUB", price: 2120, stars: 1000, packs: [{stars:500,count:2}] },
//   fragment: { stars: 1000, usd: 15, currency: "RUB", local: 1259.25 },
//   saving: 0.4060 }

appStorePlan(stars, store = "us")

The App Store packs to buy: the smallest total at or above stars that the country's packs can make, in the fewest purchases. Throws a RangeError for an unknown country.

appStorePlan(1200, "us").packs;
// [{"stars":1000,"count":1},{"stars":100,"count":2}]

fragmentPlan(stars, currency = "USD")

Fragment's price for stars (at least its minimum), in dollars and, when the snapshot has a rate, in currency.

fragmentPlan(10);         // { stars: 50, usd: 0.75, currency: "USD", local: 0.75 }

starsToUsd(stars) / usdToStars(usd)

Stars to dollars and back at Fragment's flat rate.

starsToUsd(1000); // 15
usdToStars(15);   // 1000

STORES, APP_STORES, FRAGMENT_USD_PER_STAR, USD_RATES

The snapshot itself: every country's packs with the date they were read, Fragment's rate and minimum, and the exchange rates.

TypeScript

Types ship in src/index.d.ts and load automatically.
