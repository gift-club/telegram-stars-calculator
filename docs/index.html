Telegram Stars calculator for JavaScript

Work out what any number of Telegram Stars costs on Fragment and in the App Store in 18 countries, in Node.js or the browser. No dependencies, no network calls.

Prices read: 2026-10-30

1,000 Telegram Stars cost $15.00 on Fragment and $19.99 in the US App Store, so Fragment is 25% cheaper per Star. The package returns those figures for any amount and country.

Install

npm install @gift-club/telegram-stars-calculator
import { compare } from "@gift-club/telegram-stars-calculator";

const r = compare(1000, "us");
r.fragment.usd;     // 15
r.appStore.price;   // 19.99
r.saving;           // 0.2496

compare() returns both prices, the packs to buy in the App Store, and the saving. Fragment sells any amount from 50 Stars at $0.015 each; the App Store sells fixed packs, so the plan rounds up to the smallest amount the packs can make.

Drop-in widget

One script tag adds a <telegram-stars-calculator> element in nine languages. It runs entirely in the page, renders no links and sends no requests.

<script type="module" src="https://cdn.jsdelivr.net/npm/@gift-club/telegram-stars-calculator@1.0.0/src/widget.js"></script>
<telegram-stars-calculator lang="en" store="us" stars="1000"></telegram-stars-calculator>

What it does

  • Prices any amount from 1 to 100,000 Stars in 18 App Store countries, in each store's own currency.
  • Finds the App Store packs to buy: the smallest amount at or above what you asked for, in the fewest purchases.
  • Converts Fragment's dollar price into each store's own currency at a dated central-bank rate.
  • Ships TypeScript types, ES modules and tests; runs in Node 18+ and every modern browser.

Questions

How much are 1,000 Telegram Stars in dollars?

$15.00 on Fragment and $19.99 in the US App Store.

Does the package fetch live prices?

No. It ships a dated snapshot so results are repeatable and work offline. Update the package to get newer prices.

Can I use it in a commercial app or bot?

Yes, it is MIT licensed.

Why is there no Google Play price?

Google Play publishes no public price list to read, so the package only covers Fragment and the App Store.
