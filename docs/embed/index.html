Embed the calculator on your site

Two ways to put a Telegram Stars calculator on your page. Both are free.

Option 1: iframe

Paste this where the calculator should appear. It shows the current prices and fits columns from 320 px wide.

<iframe src="https://giftclub.app/embed/telegram-stars-calculator" title="Telegram Stars calculator" width="100%" height="880" style="max-width:480px;border:0;display:block" loading="lazy"></iframe>

A credit line under it is welcome, never required:

<p style="max-width:480px;font-size:14px">Telegram Stars calculator · <a href="https://giftclub.app/tools/telegram-stars-calculator">Gift Club</a></p>

Preview

Option 2: web component

Self-hosted and fully styleable: the script runs in your page, renders no links and makes no requests.

<script type="module" src="https://cdn.jsdelivr.net/npm/@gift-club/telegram-stars-calculator@1.0.0/src/widget.js"></script>
<telegram-stars-calculator lang="en"></telegram-stars-calculator>

Match your theme with CSS variables:

telegram-stars-calculator {
  --tsc-bg: #0d0b14;
  --tsc-ink: #f3f0fa;
  --tsc-muted: #a59fb5;
  --tsc-line: #2a2535;
  --tsc-accent: #ffcf4a;
}

Questions

Is it free to embed?

Yes, for any site, commercial included.

Does the embed track visitors?

The web component sets no cookies and makes no network request. The iframe is a page on giftclub.app, which counts visits with Google Analytics; use the web component if you need no third-party requests at all.

Which languages does it support?

Nine, each set with the lang attribute: English, русский, українська, español, polski, italiano, Türkçe, Deutsch and français.
