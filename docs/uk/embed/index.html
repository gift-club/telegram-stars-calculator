Вбудуй калькулятор на свій сайт

Два способи розмістити калькулятор Telegram Stars на сторінці. Обидва безкоштовні.

Варіант 1: iframe

Встав це туди, де має з’явитися калькулятор. Він показує актуальні ціни й вміщується в колонку від 320 px.

<iframe src="https://giftclub.app/embed/telegram-stars-calculator" title="Калькулятор Telegram Stars" width="100%" height="880" style="max-width:480px;border:0;display:block" loading="lazy"></iframe>

Посилання на джерело під ним вітається, але не обов’язкове:

<p style="max-width:480px;font-size:14px">Калькулятор Telegram Stars · <a href="https://giftclub.app/uk/tools/telegram-stars-calculator">Gift Club</a></p>

Попередній перегляд

Варіант 2: веб-компонент

Розміщується в тебе й повністю стилізується: скрипт працює на твоїй сторінці, не малює посилань і не робить запитів.

<script type="module" src="https://cdn.jsdelivr.net/npm/@gift-club/telegram-stars-calculator@1.0.0/src/widget.js"></script>
<telegram-stars-calculator lang="uk"></telegram-stars-calculator>

Підлаштуй під свою тему через CSS-змінні:

telegram-stars-calculator {
  --tsc-bg: #0d0b14;
  --tsc-ink: #f3f0fa;
  --tsc-muted: #a59fb5;
  --tsc-line: #2a2535;
  --tsc-accent: #ffcf4a;
}

Запитання

Вбудовувати безкоштовно?

Так, на будь-якому сайті, зокрема комерційному.

Чи стежить вбудований віджет за відвідувачами?

Веб-компонент не ставить кукі й не робить мережевих запитів. iframe — це сторінка giftclub.app, яка рахує відвідування через Google Analytics; якщо сторонні запити не потрібні зовсім, бери веб-компонент.

Які мови підтримуються?

Веб-компонент розмовляє англійською, російською, українською, іспанською, польською, італійською, турецькою, німецькою та французькою.
